# Технічне завдання: Редизайн у стилі Apple/Samsung — Повна українізація, Чистий мінімалізм, Нуль емодзі та Суворе розділення ролей

## 1. Загальний контекст
Після запуску первинного функціоналу TMA та бота проводиться рефакторинг UI/UX під суворий стандарт **Apple / Samsung (One UI / iOS)**:
1. **Повне розділення ролей:**
   - У боті та TMA клієнта відображається **виключно функціонал клієнта** (Панель клієнта).
   - У боті та TMA розробника/адміна відображається **виключно функціонал адміна** (Панель розробника).
   - Перемикач ролей (кнопки Клієнт/Адмін) **повністю видаляється**. Роль визначається автоматично за Telegram ID користувача (або параметром `?admin=true` при тестуванні).
2. **Тотальна ліквідація емодзі (Zero Emojis):**
   - Усі емодзі повністю прибираються з інтерфейсу Mini App, інлайн-кнопок, нижнього меню та текстових повідомлень бота.
   - Замість емодзі використовуються виключно акуратні SVG-іконки бібліотеки `lucide-react` у фронтенді та чиста шрифтова ієрархія в боті.
3. **Ергономіка шапки (Apple/Samsung Header):**
   - Верхню плашку «Milestone Freelance Portal» повністю видалити для максимальної економії корисного простору.
   - У самому верху розміщується компактний мінімалістичний рядок:
     - Зліва: текстовий напис («Панель розробника» або «Панель клієнта»).
     - Справа: лаконічна кругла/квадратна кнопка швидкого оновлення з іконкою `RotateCcw` (без підпису «Оновити», чистий значок).
4. **100% українізація:**
   - Усі тексти, статуси, підказки, модальні вікна та кнопки перекладаються на чисту ділову українську мову.

## 2. КРИТИЧНЕ ПРАВИЛО БЕЗПЕКИ ТА ДИСЦИПЛІНИ
- **Zero Secrets Leak:** Жодних токенів чи паролів у коді чи репозиторії.
- **Rules of Hooks:** Усі React-хуки оголошуються суворо на самому початку компонентів.
- Перед комітом обов'язково запустити `python3 scripts/security_check.py`.

## 3. Цільові файли для модифікації

### Бот (Бекенд):
- `src/bot/keyboards/reply.py` (видалення емодзі з нижніх кнопок: «Відкрити кабінет», «Головне меню»)
- `src/bot/keyboards/inline.py` (видалення всіх емодзі з усіх інлайн-кнопок клієнта, гостя та адміна)
- `src/bot/handlers/client_handlers.py` (очищення текстів та статусів від емодзі, строгий діловий стиль)
- `src/bot/handlers/admin_handlers.py` (очищення адмінських повідомлень від емодзі)
- `src/services/notification_service.py` (видалення емодзі зі сповіщень про підтвердження етапів і тікети)

### Фронтенд (Telegram Mini App):
- `frontend/src/context/TelegramContext.jsx` (автоматичне визначення ролі: `isAdmin = tgUser?.id === 8607080614 || window.location.search.includes('admin=true')`)
- `frontend/src/components/Header.jsx` (видалення старої плашки бренду та кнопок перемикання ролей; створення мінімалістичного топ-бару зі значком оновлення; картка проекту в стилі Apple/Samsung без емодзі)
- `frontend/src/components/MilestonesTimeline.jsx` (акуратні картки етапів, тонкі рамки, статуси без емодзі із SVG-іконками, кнопка «Підписати етап»)
- `frontend/src/components/SignatureModal.jsx` (лаконічне модальне вікно для розпису пальцем)
- `frontend/src/components/TicketsSection.jsx` (список правок і форма додавання без емодзі)
- `frontend/src/components/AdminDashboard.jsx` (панель розробника в стилі Apple: огляд проектів та керування статусами)
- `frontend/src/App.jsx` (суворе відображення відповідного екрана за роллю, передача reload-хендлера в топ-бар)

## 4. Детальні вимоги до редизайну

### 4.1. Очищення Telegram-бота від емодзі
1. **Нижня клавіатура (`reply.py`):**
   - Було: `🚀 Відкрити кабінет`, `📱 Головне меню`
   - Стало: `Відкрити кабінет`, `Головне меню`
2. **Інлайн-кнопки (`inline.py`):**
   - Було: `🚀 Відкрити кабінет проекту`, `🌐 Тестовий стенд`, `🎨 Figma`, `📊 Детальний статус`, `💬 Написати розробнику`, `🔍 Відкрити Демо-кабінет`, `⏳ На підтвердженні`, `🐛 Відкриті тікети`
   - Стало: `Відкрити кабінет проекту`, `Тестовий стенд`, `Figma`, `Детальний статус`, `Написати розробнику`, `Відкрити демо-кабінет`, `Очікують підтвердження ({count})`, `Відкриті тікети ({count})`, `Список проектів`, `Оновити`, `Нагадати клієнту`, `Назад до панелі`
3. **Текстові повідомлення та сповіщення:**
   - Замінити всі піктограми (`🎉`, `📌`, `💰`, `👤`, `✍️`, `👋`, `✅`, `⏳`, `🛠`, `🔒`) на чисте типографічне оформлення через жирний шрифт (`<b>`), курсив (`<i>`) та структурні відступи.

### 4.2. Шапка та Топ-бар Mini App (`Header.jsx`)
- **Повністю прибрати:**
  - Верхній блок з логотипом «Milestone Desk / Freelance Portal».
  - Пілюлю перемикача «Клієнт / Адмін».
- **Створити мінімалістичний топ-бар:**
  ```jsx
  <div className="flex items-center justify-between pb-3 border-b border-zinc-100 dark:border-zinc-800/80">
    <span className="text-sm font-semibold tracking-tight text-zinc-900 dark:text-zinc-100">
      {isAdmin ? "Панель розробника" : "Панель клієнта"}
    </span>
    <button
      type="button"
      onClick={onRefresh}
      aria-label="Оновити"
      className="p-2 rounded-xl text-zinc-500 hover:text-zinc-900 dark:text-zinc-400 dark:hover:text-zinc-100 hover:bg-zinc-100 dark:hover:bg-zinc-800 transition-colors"
    >
      <RotateCcw className="w-4 h-4" />
    </button>
  </div>
  ```
- **Картка проекту (Client View):**
  - Статус без крапок і емодзі: витончений бейдж `В роботі` (`bg-zinc-100 dark:bg-zinc-800 text-zinc-700 dark:text-zinc-300 rounded-full px-2.5 py-0.5 text-xs font-medium`).
  - Чітка типографіка: назва проекту, загальний бюджет, затверджена сума.
  - Прогрес-бар у стилі iOS: плавний монохромний або акуратний індиго-трек без кислотних градієнтів.
  - Кнопки посилань `Figma` та `Тестовий стенд` з лаконічною іконкою `ExternalLink`.

### 4.3. Етапи робіт (`MilestonesTimeline.jsx`)
- Картки з радіусом `rounded-2xl`, м'якою тінню та тонкими межами `border-zinc-200/60 dark:border-zinc-800/80`.
- Статуси етапів:
  - `APPROVED` $\to$ «Затверджено» (іконка `Check`, стриманий смарагдовий бейдж).
  - `WAITING_APPROVAL` $\to$ «Очікує затвердження» (іконка `Clock`, стриманий бурштиновий бейдж).
  - `IN_PROGRESS` $\to$ «В роботі» (іконка `Play`, стриманий синій бейдж).
  - `LOCKED` $\to$ «Черга» (іконка `Lock`, нейтральний сірий бейдж).
- Кнопка підписання для активного етапу: `[ Підписати етап ]` (чорна в світлій темі / біла в темній темі, радіус `rounded-xl`, тач-таргет 44px).

### 4.4. Цифровий підпис (`SignatureModal.jsx`)
- Чисте полотно Canvas із ледь помітною пунктирною базовою лінією для підпису.
- Кнопки дій:
  - `[ Очистити ]` (текстова/контурна кнопка).
  - `[ Затвердити етап ]` (головна акцентна кнопка).

### 4.5. Правки та тікети (`TicketsSection.jsx`)
- Заголовок секції: «Правки та запитання».
- Кнопка додавання: `[ Додати запит ]` з іконкою `Plus`.
- Бейджі типів: «Баг», «Правка», «Запитання».
- Статуси: «Відкрито», «В роботі», «Вирішено».

### 4.6. Панель розробника (`AdminDashboard.jsx`)
- Відображається суворо для адміна.
- Компактні картки проектів із прогресом і кнопками оперативного перемикання статусів.

## 5. Критерії готовності (Definition of Done)
1. Усі емодзі на 100% видалено з коду бота (`reply.py`, `inline.py`, `handlers`, `notifications`) та фронтенду.
2. Верхній банер «Milestone Desk» та перемикач ролей повністю видалено.
3. Угорі відображається тільки «Панель розробника» або «Панель клієнта» з круглою кнопкою перезавантаження (`RotateCcw`).
4. Фронтенд успішно компілюється командою `npm run build` у `frontend/dist`.
5. Тести бота `python3 -m src.scripts.test_phase3_bot` адаптовано під нові назви кнопок (без емодзі) і вони проходять на 100%.
6. `python3 scripts/security_check.py` проходить із кодом 0.
7. Надано звіт та команду git commit.
