# Технічне завдання: Розширення Telegram-бота (Фаза 3+) — Інтерактивні інлайн-клавіатури, Persistent Reply-кнопка «Головне меню» та Демо-кабінет

## 1. Загальний контекст
У межах Фази 3 реалізовано базові хендлери бота для клієнта та адміна зі сповіщеннями.
Мета цього завдання — перетворити бота на зручний інструмент оперативного керування без зайвого візуального сміття, додавши:
1. **Persistent Reply-клавіатуру** (під полем вводу тексту), щоб користувач міг миттєво повернутися до головного меню або відкрити Mini App, навіть якщо в чаті накопичилися десятки сповіщень.
2. **Зручні контекстні інлайн-кнопки для клієнта:** динамічні посилання на робочі артефакти (Тестовий стенд / Staging, Figma дизайн) та прямий контакт із розробником.
3. **Демо-режим для нових відвідувачів (гостей):** якщо бот запущено з портфоліо/Upwork людиною без активного проекту — бот пропонує «🔍 Відкрити Демо-кабінет», щоб одразу оцінити продукт у TMA.
4. **Оперативний пульт адміна:** інтерактивні черги («Очікують підтвердження», «Відкриті тікети», «Список проектів», «Оновити») з можливістю надіслати клієнту нагадування про підпис в один клік.
5. **Базове зміцнення безпеки:** валідація `auth_date` в `initData`, `html.escape` у повідомленнях, обмеження розміру підпису (200 КБ) та валідація протоколів посилань.

## 2. КРИТИЧНЕ ПРАВИЛО БЕЗПЕКИ (Zero Secrets Leak)
- **Сувора заборона на будь-які секрети чи токени в коді.**
- Для тестів/моків використовувати виключно рядки без структури токенів (наприклад, `"mock_test_token"`).
- Перед комітом обов'язково виконати `python3 scripts/security_check.py`.

## 4. Детальні вимоги до реалізації

### 4.1. Нижня Persistent Reply-клавіатура (`src/bot/keyboards/reply.py`)
- Створити `get_persistent_reply_keyboard() -> ReplyKeyboardMarkup`:
  ```python
  ReplyKeyboardMarkup(
      keyboard=[
          [
              KeyboardButton(text="🚀 Відкрити кабінет", web_app=WebAppInfo(url=web_app_url)),
              KeyboardButton(text="📱 Головне меню"),
          ]
      ],
      resize_keyboard=True,
      is_persistent=True,
  )
  ```
- Ця клавіатура додається до відповідей на `/start`, `/admin`, а також при натисканні на кнопку `📱 Головне меню`.
- При отриманні текстового повідомлення `📱 Головне меню` або `Головне меню` — спрацьовує перенаправлення на актуальний стартовий екран (для клієнта, гостя чи адміна відповідно).

### 4.2. Інлайн-клавіатури для Клієнта (`src/bot/keyboards/inline.py` & `client_handlers.py`)
1. **Коли є активний проект:**
   - Головна кнопка: `[ 🚀 Відкрити кабінет проекту ]` (`WebAppInfo`).
   - Рядок швидких робочих посилань (якщо є в БД):
     - `[ 🌐 Тестовий стенд ]` (`url=project.staging_url` — додається, якщо поле не пусте).
     - `[ 🎨 Figma ]` (`url=project.figma_url` — додається, якщо поле не пусте).
   - Сервісний рядок:
     - `[ 📊 Детальний статус ]` (callback `client_detailed_status`).
     - `[ 💬 Написати розробнику ]` (`url=f"https://t.me/{settings.ADMIN_USERNAME}"`).
2. **Коли проекту ще немає (Гість / Потенційний лід із портфоліо):**
   - Повідомлення: вітання, опис підходу до ведення проектів (без втрати правок, фіксація етапів, акти з підписом).
   - Інлайн-кнопки:
     - `[ 🔍 Відкрити Демо-кабінет ]` (`WebAppInfo(url=f"{settings.WEBAPP_URL}/app?demo=true")`).
     - `[ 💬 Обговорити проект / Замовити ]` (`url=f"https://t.me/{settings.ADMIN_USERNAME}"`).
     - `[ ℹ️ Як це працює ]` (callback `guest_faq_how_it_works`).
     - `[ ⭐ Чому не Trello/Jira? ]` (callback `guest_faq_advantages`).

### 4.3. Інлайн-клавіатура та дії для Адміна (`admin_handlers.py`)
1. **Головна картка адміна:**
   - `[ 👨‍💻 Відкрити адмін-кабінет ]` (`WebAppInfo`).
   - `[ ⏳ На підтвердженні ({m_count}) ]` (callback `admin_waiting_milestones`).
   - `[ 🐛 Відкриті тікети ({t_count}) ]` (callback `admin_open_tickets`).
   - `[ 📁 Список проектів ]` (callback `admin_all_projects`).
   - `[ 🔄 Оновити дані ]` (callback `admin_refresh_dashboard`).
2. **Обробники нових дій:**
   - `admin_waiting_milestones`:
     - Показує перелік етапів, що очікують підпису клієнта (Проект, Назва етапу, Сума, Клієнт).
     - Під кожним етапом кнопка: `[ 🔔 Нагадати клієнту ]` (callback `admin_remind_client:{milestone_id}`).
   - `admin_remind_client:{milestone_id}`:
     - Надсилає делікатне повідомлення клієнту:  
       *"⏳ Привіт! Етап <b>«{title}»</b> готовий до перегляду та підписання. Будь ласка, перегляньте його в кабінеті проекту, щоб ми рухалися далі за графіком."*
     - Викликає `call.answer("Нагадування надіслано клієнту!", show_alert=False)`.
   - `admin_refresh_dashboard`:
     - Перераховує кількість проектів, етапів та тікетів у БД і оновлює повідомлення адміна на місці (`edit_text`).
   - `admin_open_tickets`:
     - Виводить короткий список відкритих правок із кнопками швидкого вирішення.

### 4.4. Базове зміцнення безпеки (з попереднього аудиту)
- `src/core/security.py`: перевірка віку `auth_date` (не старше 24 годин).
- `src/services/notification_service.py`: екранування через `html.escape` усіх користувацьких змінних.
- `src/schemas/milestone.py`: обмеження `signature_data` (макс 200 КБ).
- `src/schemas/ticket.py`: валідація схеми `http://` / `https://` для `attachment_url`.

  4. Адмінських callback-дій (`admin_waiting_milestones`, `admin_remind_client`, `admin_refresh_dashboard`).
